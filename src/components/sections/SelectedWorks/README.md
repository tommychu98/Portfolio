# Selected Works

Owns the Personal Works project stage and project details. PersonalWorks.jsx preserves the existing App import; unrelated project sections are unchanged.

## Structure

- SelectedWorks.data.js: confirmed content, colors, local assets and links.
- CardStage / ProjectCards / ProjectTitle: viewport stage, paired media and centered title/actions.
- ProjectDetail: native modal, independently scrollable copy, images and links.
- SelectedWorks.motion.js: section-scoped ScrollTrigger, one scroll position for cards/title/color, detail transition and cleanup.

## Reference observations

Reference inspected live at 1440×1000 and 390×844, including entry, scroll midpoint, next project, detail opening, detail scroll and Back Home. Evidence is in artifacts/selected-works/reference-*.png and reference-*-states.json.

Landscape cards are 60svh, 9:13, with a radius equal to 10% of card height; portrait uses 44svh. The source randomizes active card rotations (landscape 6–18°, portrait 2–8°) and offsets. This implementation uses deterministic 14° / 5° rotations to make reverse scrolling reproducible. Landscape projects move along a 225vmax radius; portrait retains a layered stack. Cards collapse and titles disappear between project stops, then spread as the next title appears. The title uses locally installed Lora, with an italic second line.

Details preserve the same cards and color. Landscape moves the composition left and scales it to .8 while the right half reveals text; portrait moves cards toward opposing corners. Back Home restores the original selection, scroll position and focus. Native dialog isolation prevents background interaction. Per the latest user request, this section keeps all motion enabled even when the system requests reduced motion.

MEDIPEEL uses the supplied renewal case study in `src/data/medipeel.js`, rendered by `MedipeelDetail.jsx` with scoped CSS. Its description follows the reference Details colors, typography, overview grid, badges and challenge blocks. The title uses the existing local Lora serif. No project period was available, so none is shown. The supplied live-site and GitHub links are the only external detail links; Figma source links are prohibited. ONDA retains its existing detail presentation.
