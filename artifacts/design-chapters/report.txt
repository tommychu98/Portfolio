07 / DIPTYQUE / DESIGN & MY ROLE — 하위 파트 구분 개선
2026-10-20

실제 구조
1. Crafting the brand experience. — 브랜드 경험 설명 + 빈티지 노트북 GIF
2. Exploring the scent. — 향 탐색 설명 + Galerie/History GIF 두 개와 캡션
3. Content that connects. — 콘텐츠 연결 설명 + 기존 ProjectList 4개 링크/hover preview
4. Better together. — 협업 역할 설명 두 문단 + 기존 WorkFolder 카드/영상/상세 보기
기존 순서, 제목과 설명 문구, 이미지·영상은 유지했다.

구분 방식
- 각 article에 제목을 연결하는 aria-labelledby 추가.
- 각 파트 시작에 01–04 / 04 번호, 1px 선, DIPTYQUE 라벨을 같은 규칙으로 배치.
- 선은 기존 --line, 번호는 기존 --teal-dark를 사용한다.
- 기존 글로벌 07 번호, 베이지 배경, 글꼴, Header, 콘텐츠 gutter를 유지.
- 세로 배치: 파트 상단 144px / 하단 128px / 그룹 간격 40px.
- 모바일: 상단 80px / 하단 96px / 그룹 간격 32px.
- 가로 파트 사이에 clamp(200px,24vw,400px) 간격 추가(1440px 화면에서 345.6px).
- 기존 가로 Pin에서는 상단 24px / 하단 36px로 조정해 한 화면에 수용.
  높이 740–820px에서는 12px / 16px 및 간격 20px.
- 제목→설명 간격 32px, 모바일 24px.
- 노트북은 기존 비율을 유지하고 가로 Pin의 가용 높이에 맞춰 최대 너비만 제한.
- 기존 두 GIF의 오프셋 구성, 링크 목록, 폴더 구성을 카드 그리드로 바꾸지 않았다.

모션
- 제목 4개: 기존 attachTextReveal의 Character Mask Reveal 재사용.
- 번호 opacity, 선 scaleX, 본문 y16/opacity; 약간 겹치는 .5–.7초 전환.
- 첫 두 파트의 정적인 비주얼 그룹에만 y10/opacity 진입 추가.
- 첫 파트는 세로 진입 기준, 이후 가로 파트는 기존 부모 tween을
  ScrollTrigger containerAnimation으로 참조한다.
- 새로운 Pin 없음. 기존 initHorizontal 및 scrub/이동 거리/컨트롤 코드는 변경하지 않음.
- ProjectList, WorkFolder 내부의 기존 GSAP 효과는 변경하거나 중복 적용하지 않음.
- 완료된 파트는 화면 크기를 전환해도 다시 분할/재생하지 않도록 관리.
- 모션 감소 설정에서는 새 효과를 생략하고 원본 표시. Unmount 시 cleanup.
- 공통 reveal 확장은 선택적 scrollTrigger/onComplete 인자에 한정하며
  다른 챕터의 기본 진입 조건은 유지했다.
