# DIPTYQUE UX Case Study — Section 08

2026-10-18. `08 / DIPTYQUE / UX PLANNING PROCESS`를 Interactive Research Archive로 변경했다. 01~06 선택으로 섹션 내부 설명·자료·Key Finding을 전환한다. 데스크톱은 정보 패널 35%와 문서 아카이브 65%, 모바일은 세로 구성이다. 이 섹션의 가로 스크롤·pin은 제거했고, 공용 스타일·폰트·색상 및 다른 섹션은 수정하지 않았다.

## 자료와 서술 원칙

- [자료조사 페이지](https://www.figma.com/design/DwbaDAovYNR7jMSBg62PQs/?node-id=204-23)와 [자료분석 완성 페이지](https://www.figma.com/design/DwbaDAovYNR7jMSBg62PQs/?node-id=433-2568)를 모두 확인했다.
- 원본 인터뷰 답변, 팀의 분석, 설계 가설을 구분했다. 퍼소나의 이름·나이·직업은 실제 응답자 신원으로 소개하지 않는다.
- 팀 자료에 없는 인터뷰 수, 테스트 수행, 개선 성과, 개인 리서치 역할을 추가하지 않았다.
- 05의 정체성 이해도 4.0/5, 제품 상세 이동률 20%, 연결 이유 설명 75%는 린 캔버스에 적힌 **검증 목표**이다. 테스트 계획과 목표를 실험 결과로 소개하지 않는다.
- 시장·경쟁사 초안은 팀이 수집·정리한 2차 자료로 제시한다. 원문의 시장 수치를 독립적으로 검증된 최신 사실이나 프로젝트 성과로 재인용하지 않았다.
- 사용자 추가 지시 **“와이어 프레임은 일단 보류”**를 반영했다. 06은 보류 상태이며 이미지를 넣지 않았다. 같은 파일의 발표 장표 `3823:5803`은 확인했지만 최종 원본으로 단정하거나 재사용하지 않았다.

## 이미지 선택과 인터랙션

- 큰 제목과 여백, 기존 Anton·Barlow·Noto Sans KR와 paper·teal 토큰을 사용했다. 장식 이미지·핀·실·코르크보드는 표시하지 않는다.
- 데스크톱에서 2~3개의 실제 문서를 겹치고 마우스로 선택하면 앞으로 이동·확대·정렬된다. 문서 비율에 따라 종이 폭을 달리한다. 모바일은 겹침 없이 한 장을 표시하고 버튼으로 자료를 변경한다. 태블릿의 뒤 문서는 한 번 탭해 선택하고, 선택된 문서를 다시 탭해 상세 보기를 연다.
- 단계 버튼은 방향키·Home·End로 이동할 수 있다. 자료 선택 버튼과 상세 보기는 키보드로 사용할 수 있다. 모바일 단계 목록은 가로 스크롤한다.
- 단계 전환은 하나의 GSAP Timeline에서 이전 텍스트·문서 퇴장 → 다음 문서 순차 등장 → 제목·설명 → Key Finding을 연결한다. 새 선택 시 이전 Timeline을 취소한다. 진입 ScrollTrigger는 한 번만 재생하며 pin·scrub은 없다.
- reduced-motion에서는 GSAP 전환 및 CSS 주석 모션을 생략한다. 언마운트 시 해당 섹션의 context와 media만 정리한다.
- 실제 연구 자료에는 RESEARCH, 분석 자료에는 ANALYSIS, IA·메뉴·흐름에는 OUTPUT을 표시한다. 연구 자료를 KEY FINDINGS 이미지로 잘못 표기하지 않고, 핵심 내용은 별도의 Key Finding과 Reading Note로 제시한다.
- Reading Note는 기존 자료 설명과 인사이트에 근거해 단계별 최대 두 항목만 제공한다. 이미지의 임의 지점에 선을 그리지 않고 문서 옆에 배치하며, 주석 밑줄만 그려진다.
- 이미지의 크기를 예약하고 lazy loading·비동기 decoding을 적용한다. 선택한 단계의 문서만 마운트하며 원본 이미지는 변경하지 않는다.
- 문서 클릭 시 별도의 읽기 화면으로 펼친다. 전체 이미지 맞춤 보기와 원본 픽셀 너비의 크게 보기, 스크롤·Figma 링크를 제공한다. 응답 요약도 읽기 화면에서 큰 HTML 텍스트로 볼 수 있다.
- Escape 또는 닫기로 이미지 확대창을 종료한다. 열었던 버튼에 포커스를 돌려주고 확대 중 배경 스크롤은 정지한다.
- 원본의 픽셀·문구를 수정하지 않았다. 임시 Figma URL을 런타임에서 사용하지 않는다.

## 채용 담당자 관점의 연결

1. 문제: 제품 구매는 가능하지만 브랜드와 향을 이해하는 경험이 부족하다.
2. 근거: 브랜드·시장·운영 환경 조사, 경쟁사 비교, 실제 인터뷰 질문과 답변.
3. 사용자 불편: 향의 분위기가 와닿지 않고, 제품끼리 비교하거나 브랜드 이야기를 이해하기 어렵다.
4. 분석: 다섯 범주의 어피니티 → 단계별 행동·감정·문제·기회를 연결한 여정지도.
5. 설계: 브랜드 몰입 가설 → ABOUT의 역사·향 이야기, GALERIE의 향 탐색, 관련 제품으로 연결되는 SHOP 경로. 바로 구매하려는 사용자를 위한 분기도 유지한다.
6. 화면 반영: 최종 와이어프레임 보류. 현재는 IA와 사용자 흐름까지만 근거를 제시한다.
